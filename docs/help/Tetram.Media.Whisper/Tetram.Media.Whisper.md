# Tetram.Media.Whisper Module

## Description

Transcription des pistes audio via le binaire Purfview Standalone Faster-Whisper. Une seule commande exportée. Importer `.\Tetram.Media.Whisper`.

## Tetram.Media.Whisper Cmdlets

### [Get-MediaTranscript](Get-MediaTranscript.md)

Transcrit une piste audio d'un fichier média avec faster-whisper.
