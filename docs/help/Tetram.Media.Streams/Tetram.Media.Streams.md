# Tetram.Media.Streams Module

## Description

Round-trip MKV : extraire des fichiers de flux (A/V/S) ; réinjecter uniquement les sous-titres. Deux commandes exportées. Importer `.\Tetram.Media.Streams`.

## Tetram.Media.Streams Cmdlets

### [Merge-MediaSubtitle](Merge-MediaSubtitle.md)

Réinjecte un sous-titre explicite dans le MKV (`-Add` ou `-Update`).

### [Get-MediaStream](Get-MediaStream.md)

Extrait des flux d'un MKV vers des fichiers de flux à côté du fichier.
